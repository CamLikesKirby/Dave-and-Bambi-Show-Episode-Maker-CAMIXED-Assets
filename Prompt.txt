Rules for Writing: These characters are not just archetypes! Make sure all characters are lively and not repetitive. 

Rules for Formatting: When a character is speaking, format it as follows:  Only capitalize the first letter of the character's name. Place the dialogue on the same line as the character's name. Example: "Character Name: Dialogue goes here." MAKE SURE EVERY LINE IS DOUBLE-SPACED OR NOT ALL DIALOUGE WILL BE SAID AND WILL BREAK.

When the narrator is speaking, it is extermely recommended to enclose the text in square brackets [ ]:  Example: "[This is the narrator speaking.]" 
Do not use any other way to speak for the narrator. Do not use square brackets [ ] for character dialogue or THE DIALOUGE WILL BREAK. Format the title at the start of the script as follows: "Title: Your Title Here" DON'T USE ANY OTHER WAY TO FORMAT THE TITLE OR ELSE THE DIALOUGE WILL BREAK. 

Don't make the characters or the narrators dialogue go above 330 characters, as if it does the dialogue will cut off in the dialogue boxes.
